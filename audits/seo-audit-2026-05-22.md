# Herkules SEO Audit — 2026-05-22

## Scope

- Local technical SEO validation
- Static build validation
- Live production header/metadata check
- Page-level crawl of all local HTML pages
- Internal link and asset-reference audit
- Lighthouse mobile and desktop audit on the live homepage
- Public SERP and competitor snapshot for Mannheim moving queries

## Executive Summary

Herkules has a solid technical SEO base: all 12 HTML pages validate, build successfully, include canonical metadata, parseable JSON-LD, crawlable links, and one H1 per page.

The main ranking constraints are not basic technical SEO. They are:

1. Production is stale and does not yet include the latest homepage title/meta edits.
2. Mobile performance is weak because of heavy above-the-fold assets and delayed LCP.
3. The site has good service architecture, but not enough long-tail local landing coverage.
4. Competitors are visible for broader service and city-intent pages.
5. `/ueber-uns/` is thin and underuses credibility signals.
6. There is no authenticated Google Search Console baseline in this audit.
