# Herkules SEO Audit

Audit date: 2026-05-11  
Site: https://www.umzuege-herkules.de/  
Scope: local source HTML, generated `dist/`, sitemap, robots files, Vercel routing config, structured data, metadata, internal links, image accessibility, and asset weight.

## Executive Summary

Overall SEO health is good. The site has a complete static page set, clean production canonicals, indexable robots directives, sitemap coverage for all 12 HTML pages, Open Graph/Twitter metadata, and strong local-service schema coverage.

The main issues to prioritize are image alt text review, a few internal contact-route checks that depend on Vercel redirects, and copy quality in two H1s where the target keyword is repeated. The FAQ contrast fix was also applied in `styles.css` so FAQ answer text is no longer low-contrast gray.

## Validation Results

- `npm run validate`: passed for 12 HTML pages.
- `npm run build`: passed, pre-rendered 12 routes into `dist/`.
- Sitemap coverage: all 12 local HTML routes are represented.
- Robots: allows crawling and points to `https://www.umzuege-herkules.de/sitemap.xml`.
- Canonicals: all pages use the production `https://www.umzuege-herkules.de/` domain.
- Structured data: valid JSON-LD parsed across audited pages.
- Browser/local check: `http://localhost:3000/#faq` loads and the FAQ answer text is readable after the CSS fix.

## What Is Working Well

- Every page has a title, meta description, canonical, favicon, Open Graph title, Twitter summary card, and JSON-LD.
- Titles and descriptions are within practical SEO length ranges with no duplicates found in the local audit.
- Each page has exactly one H1.
- Sitemap includes all core pages and uses clean production URLs.
- `robots.txt` allows crawling and references the sitemap.
- Vercel config defines clean URLs, trailing slashes, redirects from `.html` URLs, and long-lived cache headers for assets.
- Schema coverage is strong: 12 `MovingCompany`, 8 `Service`, 9 `FAQPage`, and 1 `WebSite` entries.
- Service pages are locally relevant and target Mannheim or Frankfurt intent clearly.
- `llms.txt` and `llm.txt` are present for answer-engine context.

## Findings

### High Priority

1. Review image alt text across service and proof images.
   - Audit found 120 image tags with empty or missing `alt`.
   - Some are likely decorative and can stay empty, but service cards, trust icons, process images, and Google/review visuals should have descriptive alt text where they add meaning.
   - SEO impact: improves image search eligibility, accessibility, and page comprehension.

2. Contact navigation depends on Vercel routing.
   - Source HTML links use `/kontakt/`.
   - No local `kontakt.html` exists, but `vercel.json` redirects `/kontakt/` to `/#kontakt`.
   - Production should be fine if deployed through Vercel; simple local static servers show `/kontakt/` as 404 because they do not apply Vercel redirects.
   - Recommendation: keep the Vercel redirect, and optionally change repeated nav/footer links to `/#kontakt` if local/static portability matters.

### Medium Priority

3. Homepage H1 repeats the target keyword.
   - Current: `Umzugsfirma Mannheim Umzugsfirma Mannheim stressfrei umziehen`
   - Recommendation: make it natural, for example `Umzugsfirma Mannheim fuer stressfreie Umzuege`.

4. Frankfurt page H1 repeats the target keyword.
   - Current: `Umzugsfirma Frankfurt Umzugsfirma Frankfurt stressfrei umziehen`
   - Recommendation: make it natural, for example `Umzugsfirma Frankfurt fuer stressfreie Umzuege`.

5. Ueber-uns H1 has a copy spacing issue.
   - Current text renders as `mitVerantwortung`.
   - Recommendation: change to `mit Verantwortung`.

6. Confirm `/stundenpreise/` in production after deployment.
   - `vercel.json` and `dist/stundenpreise/index.html` support the route.
   - The simple local source server returned 404 for `/stundenpreise/` because the root-level clean-URL shim directory is absent and ignored by `.gitignore`.
   - Production on Vercel should resolve it through build output and rewrites.

### Low Priority

7. Refresh sitemap `lastmod` values when pushing content or SEO changes.
   - Most entries show `2026-05-03`, with `stundenpreise` at `2026-05-07`.
   - Search engines treat `lastmod` as a hint, so it should reflect meaningful page changes.

8. Asset library is heavy.
   - `assets/` is about 49 MB.
   - Several large PNGs exceed 1 MB, and some older/generated screenshots appear to live at repo root.
   - Recommendation: keep production assets in optimized WebP/WebM where possible and avoid shipping unused screenshots or source media.

9. Social image is shared across all pages.
   - All pages use `herkules-truck-poster.png`.
   - This is acceptable, but page-specific OG images for high-value service pages could improve social previews.

## Recommended Next Fix Order

1. Add meaningful alt text to non-decorative service, process, and trust images.
2. Clean up the repeated H1 wording on the homepage and Frankfurt page.
3. Fix the `mitVerantwortung` spacing on the Ueber-uns page.
4. Decide whether `/kontakt/` links should remain as Vercel redirects or be changed to `/#kontakt`.
5. Verify `/stundenpreise/` on the deployed Vercel URL after push.
6. Update sitemap `lastmod` values when SEO/content edits are deployed.
7. Remove or ignore unused local screenshot artifacts if they are not part of the site deliverable.

## Notes

- This was a local technical and on-page SEO audit. It did not include Google Search Console, live crawl logs, backlink analysis, rankings, or Core Web Vitals field data.
- Production routing findings assume Vercel is the deployment target because `vercel.json` is present and `npm run build` emits `dist/`.
